## 🎯 Complete Tutor Application Workflow

### Step 1: Manager Posts Tutor Vacancy
1. **Login as manager**: `manager@smarttutor.com / password123`
2. **Go to Courses page** (from sidebar)
3. **Find your course** and click **"View Details"**
4. **Click "Post Tutor Vacancy"** button (blue button)
5. **Fill the form**:
   - Requirements: "5+ years experience in web development"
   - Deadline: Select a future date
6. **Click "Post Vacancy"**

**Result**: Course now has open vacancy ✅

---

### Step 2: Tutor Applies to Course
1. **Register as tutor** (or login if already registered)
2. **Go to Courses page**
3. **Find the course with open vacancy** (from Step 1)
4. **Click "View Details"**
5. **Click "Apply to Teach"** button (appears only for tutors)
6. **Fill the form**:
   - Cover Letter: "I have 5 years of experience..."
   - Experience: "Taught web development at..."
7. **Click "Submit Application"**

**Result**: Application submitted, status = "pending" ✅

---

### Step 3: Manager Reviews Application
1. **Login as manager**
2. **Go to Manager Dashboard**
3. **See "Tutor Applications" section**
4. **Find the application** and click **"Approve"** or **"Reject"**
5. **If rejecting**, enter reason

**Result**: Application reviewed, tutor notified ✅

---

### Step 4: Tutor Receives Notification
1. **Login as tutor**
2. **Go to Notifications page**
3. **See approval/rejection notification**

**Result**: Tutor knows application status ✅

## 🔍 Troubleshooting

### Issue: "Apply to Teach" button not showing
**Solution**: Make sure:
1. You're logged in as tutor
2. Course has open vacancy (manager posted it)
3. You haven't already applied

### Issue: "Post Tutor Vacancy" button not showing
**Solution**: Make sure:
1. You're logged in as manager
2. You created the course
3. Course doesn't already have vacancy

### Issue: Applications not appearing in Manager Dashboard
**Solution**: Make sure:
1. Tutor applied to your course
2. Application status is "pending"
3. Refresh the page
